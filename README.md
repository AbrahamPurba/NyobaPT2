# 🚏 Halte Kediri — WebGIS Analisis Keterjangkauan Halte

Interactive WebGIS untuk menganalisis keterjangkauan halte terhadap kawasan permukiman, area publik, dan area komersial di Kota Kediri menggunakan buffer analysis berbasis QGIS dan Leaflet.

---

## 📌 Tentang Project
Project ini dibuat untuk menganalisis seberapa jauh jangkauan pelayanan halte terhadap berbagai fungsi kawasan perkotaan di Kota Kediri.

Analisis dilakukan menggunakan:
- QGIS
- Leaflet.js
- OpenStreetMap
- GeoJSON
- Buffer Analysis

---

## ✨ Fitur Utama
✅ Visualisasi persebaran halte  
✅ Analisis buffer 400m & 800m  
✅ Overlay jaringan jalan  
✅ Interactive Layer Control  
✅ WebGIS interaktif berbasis Leaflet

---

## 🗺️ Layer yang Digunakan

| Layer | Fungsi |
|---|---|
| Halte_Kediri | Titik lokasi halte |
| AreaPerumahan_Terlayani | Area permukiman terjangkau |
| AreaPublik_Terlayani | Area publik terjangkau |
| AreaKomersial_Terlayani | Area komersial terjangkau |
| Clipped_400 | Buffer 400 meter |
| Clipped_800 | Buffer 800 meter |
| Jaringan_Jalan | Network jalan |
